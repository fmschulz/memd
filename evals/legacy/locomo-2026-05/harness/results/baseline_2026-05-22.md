# LoCoMo Retrieval Benchmark

This is a direct retrieval benchmark on upstream `locomo10.json`: each system is seeded with the same conversation turns and scored against LoCoMo evidence IDs.

- Dataset: `datasets/locomo/locomo10.json`
- Categories: `1, 2, 3, 4`
- Top-k: `10`
- Questions: `1536`
- Facts: `5882`
